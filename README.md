# alxenavcam — Realtime Android Media Processing & Output Pipeline (Non-Root)

`alxenavcam` (`com.alxenavcam`) adalah aplikasi pemrosesan video, foto, dan audio secara *realtime* berbasis **OpenGL ES 2.0** dan **MediaCodec Hardware Acceleration** untuk perangkat Android **NON-ROOT**.

## Cara Build APK
1. Buka folder `alxenavcam` di **Android Studio** lalu jalankan menu **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
2. Atau upload repository ini ke **GitHub**, buka tab **Actions**, dan unduh file `app-debug.apk` serta `app-release.apk` secara otomatis.
